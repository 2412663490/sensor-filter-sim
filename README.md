# sensor‑filter‑sim
> 嵌入式温度传感器仿真框架，Qt(qmake/C++11)笔试项目。

## ✨项目功能
1. **HAL硬件抽象层**：分离上层业务与硬件驱动。
2. **多种滤波器实现**：滑动平均滤波、中值滤波、一维卡尔曼滤波，支持传感器接入多滤波器做数据平滑。
3. **观察者模式解耦**：
   - GUI观察者：控制台打印温度数据
   - MQTT观察者：模拟传感器数据上报
   - Business观察者：模拟业务告警判断
4. 业务逻辑完全不依赖底层硬件，替换HAL驱动即可适配真实硬件。

## 🛠编译环境
- Qt Creator
- Qt 5.6.3 MinGW 32bit
- C++11，qmake构建，Console控制台程序

## 🚀编译&运行步骤
1. 使用Qt Creator打开 `blueair_sensor_framework.pro`
2. 执行 qmake
3. 构建项目，直接运行可执行程序
4. 控制台周期性输出仿真温度采样、滤波后结果、业务日志。
